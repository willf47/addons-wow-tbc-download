# Addons TBC Anniversary

**[Baixar o pack completo](https://github.com/willf47/addons-wow-tbc-download/releases/latest/download/addons-wow-tbc.zip)**

## Como instalar

1. Baixe o ZIP pelo link acima.
2. Extraia o conteudo em `World of Warcraft\_anniversary_\Interface\AddOns`
3. Abra o jogo.

O arquivo e regenerado automaticamente a cada atualizacao do pack.
